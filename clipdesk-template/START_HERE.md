# Começar aqui

Abra um **Claude Code** nesta pasta e digite:

> leia BUILD_GUIDE.md e me guie pelo setup

O Claude Code vai conduzir o resto — vai te perguntar qual nome de produto, quais sites de notícias você quer suportar, e testar cada um deles antes de registrar.

Pré-requisito: Python 3.10+ instalado.

Quando o setup terminar, o uso diário está em `README.md`.
